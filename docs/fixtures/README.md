# .psa 골든 픽스처 v1 — 병합 도구 검증용

> 사양: `ESP-STM32_SD_Logging_Extension_v1.4.md` §7 / §8.1
> 생성: `gen_golden.c` + 펌웨어와 **동일한** `User/Lib/src/lib_crc.c`
> 파일: `golden_v1.psa` (752 B = 512 헤더 + 80 × 3 레코드)

실물 카드(§14.6 Q23) 전에 파서를 맞춰 보실 수 있도록 만든 합성 픽스처입니다.
CRC는 펌웨어가 쓰는 코드가 계산했으므로 값이 갈라질 수 없습니다.

## 포함된 검증 포인트

| # | 항목 |
|---|------|
| 1 | 헤더 CRC-16/CCITT-FALSE (오프셋 0~29) |
| 2 | 레코드 CRC (오프셋 0~77), Big-Endian 필드 배치 |
| 3 | **불변식** — n번째 레코드의 seq == firstSeq + n |
| 4 | `deviceMode` = **7 (HEALING)** — v1.3에서 신설한 값이 실제로 나타남 |
| 5 | `errorMask` = **0x0200 (ERR_SD_CARD)** — 정정 ① 비트 위치 |
| 6 | **플레이스홀더** — `flags` bit1=1, payload 전체 0x00, **CRC는 정상** |
| 7 | `deviceId` 미수신 시 `FF FF FF FF FF FF` |

> 레코드 2가 §6.5의 핵심 검증입니다. **CRC를 통과하지만 유효한 샘플이 아닙니다.**
> `flags` bit1을 검사하지 않으면 0으로 채워진 IMU·FSR·ToF가 그대로 분석에 섞입니다.
