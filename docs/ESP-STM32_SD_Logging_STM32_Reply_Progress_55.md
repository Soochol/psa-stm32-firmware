### 1.1 다만 아직 아무도 못 봤습니다

**reason 7은 삭제가 실패해야 나갑니다.** 정상 삭제에는 아무 영향이 없으므로
RTT로도 확인되지 않습니다.

`9bd5679` 때 그쪽이 *"25 B 응답을 아직 아무도 본 적이 없습니다"* 라고 하신 것과
같은 상태인데, 한 가지가 다릅니다.

| | `9bd5679` 25 B | **reason 7** |
|---|---|---|
| 경로 | **정상** | **예외** |
| 검증 방법 | 굽고 한 번 물어보면 됨 | **고장을 만들어야 함** |

재현 방법은 델타 #54 §3에 적었습니다 — 읽기 전용 속성을 붙인 `.psa`를 카드에
하나 넣으면 `FR_DENIED`(7)가 나옵니다. **급하지 않으니 편하실 때 하시면
됩니다.** 저희가 카드를 뽑아 심어 드릴 수도 있습니다.

## 3. ⚠️ 부팅 스캔이 모델에서 벗어나기 시작했습니다

```
[D]cyc=12us sdmax=263324us n=14
[D]sdh 0 0 0 0 13 0 1 0
                   ↑ b6 에 1건
```

| 파일 수 | 모델 예측 | 실측 | 오차 | **파일당** |
|---|---|---|---|---|
| 48 | 151.5 ms | 150.9 ms | −0.4 % | 2.99 ms |
| 68 | 211.5 ms | 214.8 ms | +1.6 % | 3.05 ms |
| 73 | 226.5 ms | 231.3 ms | +2.1 % | 3.07 ms |
| **76** | **235.5 ms** | **263.3 ms** | **+11.8 %** | **3.37 ms** |

**세 지점이 2 % 안에 있다가 네 번째에서 12 %로 벌어졌습니다.**

### 3.1 선형이 아닐 수 있습니다

저희 코드 주석에 이미 이유가 될 만한 문장이 있습니다.

```c
// User/Drv/inc/sd.h:927
// each entry costs one f_open plus a 512 B header read, and f_open's
// directory walk grows with the file count
```

**`f_open`의 디렉터리 탐색이 파일 수에 비례해 늘어난다면, 총비용은 선형이
아니라 2차항을 갖습니다.** 파일당 비용이 2.99 → 3.05 → 3.07 → 3.37로 올라가는
모양이 그 방향과 맞습니다.

`7.5 ms + 3.0 ms/file`은 48개 근처에서 세운 근사이고, **그 구간에서만 선형으로
보였을 수 있습니다.**

### 3.2 그런데 결론 내기에는 이릅니다

**단일 표본입니다.** `sdmax`는 부팅당 한 번 찍히는 값이라 카드 편차를 평균낼
방법이 없습니다. 12 %는 SD 카드 자체의 산포일 수도 있습니다.

**저희는 이것을 결론이 아니라 관측 항목으로 둡니다.** 다음 부팅 두어 번의
`sdmax`를 더 모으면 산포인지 굽음인지 갈립니다.

### 3.3 왜 알려드리는가 — 128 예산이 이 위에 서 있습니다

| 가정 | 128개 예상 | IWDG 2.0 s 대비 |
|---|---|---|
| 선형 (3.0 ms/file) | 약 **390 ms** | 5.1배 |
| 3.37 ms/file | 약 **440 ms** | 4.5배 |
| 2차항이 실재하면 | 그보다 큼 | — |

**어느 쪽이든 안전합니다.** 다만 저희가 여러 문서에서 *"390 ms, 5배 여유"* 를
근거로 써 왔고(#27, #50, #53), 그 숫자가 낙관적일 수 있다는 것을 그쪽이 아는
편이 맞습니다.

| | |
|---|---|
| 상한까지 | **52개** |
| 예산 소진 | **60~67 %** (390 / 440 ms 기준) |

> **`indexCapacity`를 그쪽이 아니라 저희가 말하게 한 것(`9bd5679`)이 여기서
> 값을 합니다.** 이 예산을 다시 재서 128을 내려야 할 일이 생기면, 저희가
> 매크로만 고치면 그쪽 화면이 따라옵니다. 그쪽 #52의 *"바뀐 것은 누가
> 말하느냐입니다"* 가 가정에 그치지 않을 수 있습니다.

### 3.4 평시 블로킹은 그대로입니다

```
[D]sdh 0 0 0 0 13 0 1 0
              b4 ┘   b6 ┘
```

`b4`(10~50 ms)만 늘고 `b5`·`b7`은 0, `b6`은 부팅 스캔 1건입니다. **§3은 부팅
스캔만의 이야기이고 백필·플러시가 부딪히는 대역은 변화 없습니다.**
