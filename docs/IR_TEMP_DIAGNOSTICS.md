# 적외선 센서 최초 실패 진단

## 기준과 변경 범위

- 기준은 `a40e2ea`(PR #12 취소), 펌웨어 동작은 `6b3265b`와 동일하다.
- `i2c4_diag.c`는 RAM 스냅샷과 메인 루프의 비차단 RTT 출력만 추가한다.
- 센서 초기화 순서, HAL 타임아웃, 재시도, SCL 토글/STOP 복구, 에러 진입 조건은 바꾸지 않는다.
- ESP32 시리얼을 열거나 그 로그를 수집하지 않는다.
- 이 진단 코드는 실제 전압을 측정하지 않는다. `en12`는 12V enable 출력 신호다.

## 2026-10-27 실측

사용자가 같은 보드의 TOF·IR·외기온도 센서 세 개에 연결되는 공통 커넥터를
분리/재연결했다. IR 센서만 별도로 분리하거나 실제 VDD를 측정하기는 어렵다고 확인했다.

| 부팅 ID | 연결 상태 | 12V enable 시 SCL/SDA | 첫 IR probe 직전 | 결과 |
|---|---|---|---|---|
| 50 | 연결 | 1/0 | enable 후 2007 ms에도 1/0 | probe 실패, IR 초기화 실패 |
| 52 | 공통 커넥터 분리 | 1/1 | TOF 오류로 IR 단계에 도달하지 않음 | TOF 오류 `0x0040` |
| 54 | 공통 커넥터 재연결 | 1/0 | enable 후 2526 ms에도 1/0 | 같은 IR 초기화 실패 재현 |

연결 상태의 최초 순서는 다음과 같다.

1. 첫 I2C4 통신 전부터 PB9(SDA)가 LOW다. PB8(SCL)은 HIGH다.
2. `HAL_I2C_IsDeviceReady(0x66, 3, 100)`가 `HAL_ERROR`로 반환한다.
   HAL ErrorCode는 `0x20`(TIMEOUT), ISR은 `0x201`(ARLO 플래그 포함)이다.
3. 기존 코드는 probe 결과와 관계없이 refresh-rate 설정으로 진행한다.
4. `0x800D`의 2바이트 읽기가 실패하고 HAL ErrorCode `0x02`(ARLO)가 관측된다.
   이 읽기 전부터 ARLO 플래그가 있었으므로 읽기가 처음 ARLO를 만들었다고 해석하면 안 된다.
5. 내부 오류 비트 `0x0001`과 `modeERROR`로 진입한다.

**확인 범위:** 이 부팅 실패의 출발점은 정상 유휴 상태가 아닌 SDA이며,
LOW는 공통 커넥터 이후의 연결 경로와 함께 나타난다. 코드의 초기화 시점만으로
새로 만들어진 오류라고 볼 수 없다. 모듈 전원 불량, 센서가 선을 잡는 상태,
케이블/커넥터/보드 배선 중 어느 것이 원인인지는 아직 분리하지 못했다.
MCU 보드 전체가 완전히 정상이라거나 IR 칩 자체가 고장이라고 단정하지 않는다.

**사용 중 오류:** 이번 시험은 부팅 실패이며 정상 프레임은 0개다. 정상 사용 중의
갑작스러운 오류가 같은 원인인지는 아직 확인하지 못했다.

## 진단 출력

`[IRDIAG]`는 초기화 종료/실패나 최초 오류가 발생한 뒤, 저장된 시각 순으로 출력된다.
화면에 출력된 시각과 `t=`의 스냅샷 시각을 혼동하지 않는다.

- `op=P`: 장치 probe. `R/W`: 블로킹 읽기/쓰기. `r/w`: DMA 읽기/쓰기 시작.
- `BEFORE/AFTER`: HAL 호출 전/반환 직후. `ret`는 HAL 반환값이다.
- `RATE/MODE/EEPROM/PARAMS`: 초기화 단계. `INIT_FAIL`의 `ret=-1`은 단계 실패 표시다.
- `IRQ_ERR`: 오류 콜백 진입 시점. ISR 안에서는 출력하지 않는다.
- `TIMEOUT/RECOVERED`: 기존 복구 전/후. TIMEOUT의 `ret`는 프레임 오류 횟수다.
- `BAD_AUX/BAD_FRAME`: 통신 오류와 구분하기 위한 첫 데이터 검증 실패.
- `S/E/ISR/C1/C2`: HAL 상태/오류와 I2C4 레지스터 원본.
- `SCL/SDA`: GPIO 입력 레벨. `gm=A`: PB8/PB9 모두 AF, `gm=5`: 모두 GPIO 출력.
- `pAge`: 12V enable 이후 ms. `goodAge/frames`: 마지막 정상 온도 프레임 이후 ms/정상 프레임 수.
- `4294967295` age는 해당 시점이 아직 없음을 뜻한다.
- `lost`: RAM 큐 초과 횟수. 첫 오류는 큐와 별도로 RAM에도 보존한다.

정상 운전 중 모든 트랜잭션을 출력하지 않는다. 마지막 전송 직전 상태와 정상 프레임
시각을 갱신하다가, 오류 시 복구가 정보를 지우기 전에 기록한다. RTT가 가득 차면
출력을 재시도하며 읽지 않은 큐 항목을 제거하지 않는다.

부팅 52에서는 TOF가 먼저 실패해 IR 초기화 종료 이벤트가 없었다. SWD로 진단의
`draining` 플래그만 켜서 저장된 전원/핀 스냅샷을 출력했다. 센서나 GPIO 설정은 바꾸지 않았다.

1. 하위 보드 회로도/핀맵으로 I2C4 SDA(PB9)의 실제 연결과 IR 전원 경로를 확인한다.

4. 정상 부팅이 확보된 뒤 동일 진단 코드로 사용 중 첫 오류와 직전 정상 프레임을 수집한다.

검증: `python3 tests/test_i2c4_diag.py`, `python3 tests/test_power.py`,
`pio run -e stm32_debug -e stm32_release`.
