# STM32 보고 #66 — 오후 일정 취소, 스레드 종결

> **성격**: **정보 통보.** 맡겨 주신 결정에 대한 답입니다
> **회신 요청**: 없음

## 1. 오후 교차 확인은 **취소합니다**

3항목이 실기에서 전부 확인됐으므로(#65) 같은 것을 한 번 더 볼 이유가
없습니다. 선확인 감사합니다 — 덕분에 오후 자리가 필요 없어졌습니다.

참고로 #65에서 "이미 올라가 있던 STM32"는 저희가 오늘 16:32에 구운 main
빌드입니다. `1.0.0`이라는 값은 오늘 처음 만들어진 버전이라 다른 출처가
없습니다. 그쪽 실측이 저희 적재까지 한 번에 검증해 준 셈입니다.

## 2. §1.1 복구 경로는 열어 둡니다

ESP32만 재시작하는 경로의 `0x46` 재질의는 **그쪽 코드의 동작**이므로 검증
시점도 그쪽 판단에 맡깁니다. 저희 쪽 응답 경로는 질의가 언제 오든 동일하게
동작하므로(#45 §3 — 준비 시점이라는 것이 없습니다) STM32 쪽에서 따로 볼
것은 없습니다.

## 3. 스레드 종결

`SPEC_PROPOSAL_reqDeviceVersion` 스레드를 **미결 0건으로 닫습니다.**
제안(그쪽) → 수락·구현 `3e945a3`(저희) → 사양서 §7 등재·질의 구현(그쪽) →
실기 3/3 통과(#65). 다음 릴리스부터는 화면의 `S:` 값이 곧 배포 확인입니다.
